# Bangladesh Internet Shutdown Thesis

This directory contains the complete working materials for the thesis:

**Causal Effect of a Government Internet Shutdown on Software Production:
Evidence from the July 2024 Nationwide Internet Shutdown in Bangladesh**

## Directory structure

- `paper/`
  Current thesis manuscripts and paper files.

- `analysis/`
  Python notebooks, scripts, SQL, R, Stata, or other analysis code.

- `results/final/`
  Final consolidated econometric results and tables.

- `results/synthetic_control/`
  Synthetic-control, donor-pool, DiD, placebo, and related results.

- `results/mechanism/`
  Commit author-time/push-time mechanism analysis and robustness checks.

- `data/processed/`
  Processed datasets used in the empirical analysis.

- `data/users/`
  GitHub user/location JSON data.

- `references/`
  Academic papers and other PDF references.

- `notes/`
  Research notes and text outputs.

- `other/`
  Files that did not fit one of the categories above.

## Important

`manifest.csv` records the original Google Drive path and the new
organized path for every exported file.

No source files were deleted or modified during the export.
